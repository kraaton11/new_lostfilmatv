# Качественные постеры Android TV-канала

## Проблема

Android TV launcher получает для новых релизов путь из списка LostFilm, например `/Static/Images/362/Posters/image_s10.jpg`. Это небольшой горизонтальный thumbnail. Когда отдельного фона нет, тот же файл становится изображением фокусной карточки и размывается при увеличении.

На странице LostFilm для сезонного изображения доступен полноразмерный портрет `shmoster_s10.jpg`. В проекте уже есть `lostFilmPortraitUrl`, который находит этот вариант и разрешает его относительно выбранного зеркала.

## Решение

- При подготовке программы для Android TV-канала заменять известный сезонный thumbnail на полноразмерный портрет LostFilm.
- Если подходящего полноразмерного варианта нет, оставлять исходное изображение.
- Использовать настоящий `backdropUrl` для фокусного превью, когда он есть. При его отсутствии publisher уже использует постер, теперь в полном разрешении.
- Сохранять прямую загрузку с выбранного зеркала. Не добавлять серверный proxy, новые сетевые запросы или изменения навигации.

## Проверка

Unit-тесты должны подтверждать, что сезонный thumbnail превращается в адрес `shmoster_sN.jpg` на активном зеркале, а остальные адреса сохраняются без изменений. После сборки обновить канал на подключённой приставке и проверить резкость постера и изображения при фокусе.
